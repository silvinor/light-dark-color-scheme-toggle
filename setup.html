Finish setup

This extension changes Chrome's color preference. First, enable the Chrome feature that allows the change.

  1. Open Chrome's flags page

    chrome://flags/#enable-experimental-web-platform-features

    Paste the address into Chrome's address bar. Chrome does not allow links to its internal pages.

  2. Set “Experimental Web Platform features” to Enabled

    The flag is highlighted at the top of that page.

  3. Relaunch Chrome

    Select Relaunch at the bottom of the flags page. Chrome restores your tabs.

The toolbar button now works. The ? icon disappears.

Why is this needed? The Web Preferences API changes Chrome's prefers-color-scheme setting. Sites then use their own light or dark design. Chrome does not enable this API by default.

Alternative: If you start Chrome from a terminal, use --enable-features=WebPreferences.

The API works only on https:// pages. It does not work on http:// pages.
